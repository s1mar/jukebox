# Jukebox

A small shared jukebox for two friends. Paste a YouTube link, drop the coin, and the song
becomes a 45 in a numbered slot, with a notes thread for what it brings back.

- The app is a static page (this repo, served by GitHub Pages).
- The songs and notes live in a separate private repo, written through the GitHub API with a
  token that only the two of us hold. No token is in this repo.
- The music itself plays from YouTube's own embedded player.
